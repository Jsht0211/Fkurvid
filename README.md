# Fkurvid

## Description
A tool based on ffmpeg and python that helps you lower your video quality.

## Dependencies
`ffmpeg` and `python3` must be installed and available in PATH.

## How to start the tool
```
python3 fkurvid.py
```

## How to use
Follow the instructions and enter the arguments.

## Platform Support
Supports macOS and Linux.
